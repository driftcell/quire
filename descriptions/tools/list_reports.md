List existing reports newest first, optionally filtered by `query` (case-insensitive substring match on `doc_id` or `title`) and `limit` (1..=100, default 20). Use this only to discover or resume an existing report when `doc_id` is unknown; to start a new report, call `create_report` directly. Returns `doc_id`, `title`, `session_id`, `current_rev`, `block_count`, and `updated_at`.
