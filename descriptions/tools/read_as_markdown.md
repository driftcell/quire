Project the report or a targeted scope into token-efficient Markdown with `<!-- block:<id> | type:<type> -->` anchors.
- Scope selectors (mutually exclusive): pass `section_id` (a Heading `block_id` from `get_document_digest`, e.g. `"ch1"` or `"c2-1"`) to read that heading and all blocks in its section; pass `block_ids` to read specific individual blocks only (passing a Heading ID in `block_ids` returns only the heading line itself, not its section); omit both to read the full report.
- Built-in projections: `include_chart_data` defaults to `true`, automatically expanding ECharts series/datasets into Markdown tables (`_Chart data: ..._`) for numerical cross-checking without calling `read_blocks`. Inline citations appear as `[^source_id]` with `Sources: [^id] (Title)` or `(UNRESOLVED SOURCE)` appended below each block.
