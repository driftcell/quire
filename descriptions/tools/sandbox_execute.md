Execute `code` (up to 256 KiB) in `"python"`, `"javascript"`, or `"bash"` (`language`) inside this run's isolated remote sandbox, with optional `cwd` and `timeout_seconds`. The sandbox is provisioned on first use, persists files and installed packages across calls within the same run, and is destroyed when the run ends. Returns `exit_code`, `stdout`, and `stderr` (each capped at 64 KiB with `stdout_truncated` / `stderr_truncated` flags).
