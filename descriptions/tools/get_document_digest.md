Get a lightweight structural outline and length dashboard for a report: `current_rev`, `prose_char_count` (visible Paragraph chars excluding headings, quotes, tables, charts, and `[^source_id]` markers), `target_prose_chars`, `prose_char_delta`, `visual_block_count`, and per-block summaries (`id`, `type`, 30-char `preview`, `char_count`, `source_ids`). Optional `query` filters only the returned `blocks` list without affecting global counts. Omit `target_prose_chars` if the report already stores an agreed target (passing a conflicting value will fail). Use this for outline navigation and length checks; use `read_as_markdown` to read prose/chart data or `read_blocks` for raw block JSON.
