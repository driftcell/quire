Create or update an agent definition (`name`, `description`, `model`, `system_prompt`, `allowed_tools`, `is_default`, `enabled`) inside `branch` (prefer a `"draft"` branch). `model` must reference a route ID registered in `models_list`. `allowed_tools` supports `"*"`, `<server_id>:*`, and wildcard patterns (`prefix_*`), intersected with globally enabled MCP tools. Setting `is_default: true` automatically demotes any other default agent in the same branch.
