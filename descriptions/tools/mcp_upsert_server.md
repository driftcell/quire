Create or update an external MCP server (`server_id`, `name`, `url`, `auth_token_ref`, `enabled`). `auth_token_ref` accepts `env:VAR_NAME`, an encrypted `enc:...` reference, or a raw token (raw tokens are encrypted at rest and require `RUNTIME_MASTER_KEY`). WARNING: Updating an existing server with `auth_token_ref` omitted will clear its stored token reference. After upserting a server, you must call `mcp_sync_tools(server_id)` to discover and persist its tools.
