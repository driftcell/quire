# 高教四大调研赛道工具链下钻手册与参数规范（Track Playbooks & Tool Contracts）

本手册供 `researcher` 子代理与 `main` 主编在执行并行深度调研时查阅，确保所有内部数据库工具与外部网页抓取**一次调用成功、零参数报错、下钻到底**。

## 一、高频工具参数硬约束（防调用失败）

1. **`panorama_report_universities`（高校实体检索）**
   - 参数名为**单数字符串** `keyword: "<高校名称>"`（如 `{"keyword": "浙江工业大学"}`）。
   - **严禁传入复数数组 `keywords: [...]`**。若需查询多所高校，必须在同一轮并行发起多个单校调用。
2. **`subjectcloud_overview`（学科评估与学科指数总览）**
   - `subject_ids` 数组单次硬上限为 **10 个学科代码**（`max_length = 10`）。
   - 若目标校或对标组涉及超过 10 个一级学科（例如同时查 16 个工科、理科与经管学科），必须拆分为 **2 次并行调用**（每批 ≤ 10 个学科 ID）。
3. **`upsert_sources`（信源注册与增量更新）**
   - 每个条目必须包含合法的短语义 `id`（符合 `[a-zA-Z0-9_-]{1,48}`，如 `"sc-discipline-eval"`、`"pr-nsfc-2021-2025"`、`"moe-bulletin-2024"`）。
   - **首次注册新 `id` 时必须提供非空 `title`**；对已存在 `id` 补充 `excerpt` 或 `note` 时可按 `id` 增量合并。
   - 务必检查返回回执中的 `canonical_id_map`：若因 URL 或标题相同被自动合并到已有信源 ID，后续报告中一律使用映射后的 `canonical_id`。

## 二、四大赛道标准下钻调用链与信源命名规范

### 赛道 A：学科档位、学位点架构与 ESI 竞争力（`discipline-and-degree`）

1. **第一步：全口径学位点与学科底座扫描**
   - 调用 `panorama_report_indicator_info` 与 `panorama_report_query` 查询目标校及全部对标校的：
     - 一级学科博士学位授权点数量、专业学位博士授权点数量；
     - 一级学科硕士学位授权点数量、专业学位硕士授权点数量；
     - ESI 全球前 1% 学科数、前 1‰ 学科数及具体学科名称。
2. **第二步：学科评估与学科指数分档下钻**
   - 调用 `subjectcloud_overview`（每批 ≤10 个学科）与 `subjectcloud_result`、`subjectcloud_detail`，获取主干对比学科的档位分布（A类 / B+ / B / B- / C类）与年度学科指数位次。
   - **双口径隔离铁律**：登记信源时，将 `moe`（教育部学科评估口径）与 `index`（年度学科发展指数口径）分条或分表写明，严禁混写。
3. **第三步：分域登记信源**
   - `sc-discipline-eval`：教育部学科评估档位与参评学科结构核实记录；
   - `sc-discipline-index`：年度学科发展指数与横向位次核实记录；
   - `pr-degree-esi`：博硕士学位授权点结构与 ESI 前 1%/1‰ 学科核实记录。

### 赛道 B：师资规模与高层次人才梯队（`talent-and-faculty`）

1. **第一步：师资总量与学历职称底座**
   - 调用 `panorama_report_query` 获取专任教师总数、具有博士学位教师人数及占比、正高级/副高级职称比例、生师比。
2. **第二步：国家级领军与青年人才精细下钻**
   - 调用 `subjectcloud_talent_search`、`subjectcloud_talent_batch` 与 `subjectcloud_talent_detail`，按高校与主干学科检索：
     - 国家级领军人才（两院院士、长江学者特聘教授、国家杰青、万人计划领军人才等）存量与近五年新增；
     - 国家级青年人才（四青人才：青年长江、国家优青、海外优青、万人青拔）存量与近五年新增；
     - 人才在各一级学科的分布集中度（识别“有人才无平台”或“有博士点无领军带头人”的结构断层）。
3. **第三步：分域登记信源**
   - `pr-faculty-base`：专任教师规模、博士占比与职称结构核实记录；
   - `sc-talent-leading`：国家级领军人才与青年人才梯队及学科分布核实记录。

### 赛道 C：纵向科研项目、平台基地与标志性科技奖励（`research-and-platform`）

1. **第一步：国家自科/社科基金跨期趋势与结构拆解**
   - 调用 `panorama_report_query` 与 `panorama_report_drill` 查询 2021—2025 年（或指定时间窗）各校：
     - 国家自然科学基金立项总数、资助总经费、面上项目数、青年科学基金项目数（计算青年占比）、重点/重大/杰青优青/联合基金立项明细；
     - 国家社科基金立项总数、重大重点项目数与教育部人文社科项目数；
     - 年度科研到账总经费及纵向/横向经费占比。
2. **第二步：高能级科研平台与国家级/省部级科技奖励下钻**
   - 调用 `panorama_report_query` 与 `panorama_report_drill` 核查：
     - 全国重点实验室（牵头 vs 共建）、国家工程研究中心、教育部重点实验室、省级重点实验室/工程技术研究中心数量及具体名称；
     - 国家自然科学奖、国家技术发明奖、国家科技进步奖（第一完成单位 vs 参与单位）及省级科学技术一等奖、国家级教学成果奖明细。
3. **第三步：分域登记信源**
   - `pr-research-nsfc`：国家自然科学基金与国家社科基金历年立项结构核实记录；
   - `pr-platform-matrix`：国家级与省部级科研创新平台矩阵核实记录；
   - `pr-award-teaching`：国家级/省部级科技奖励与教学成果奖核实记录。

### 赛道 D：双优建设、区域产业契合与外部官方政策/公报原文（`policy-and-industry`）

1. **第一步：双优建设与区域产业契合度探查**
   - 调用 `shuangyou_profile`、`shuangyou_industry_source`、`shuangyou_intel_*`、`shuangyou_planning_*` 获取目标校与对标校的优势特色学科群、产业契合度得分、现代产业学院、产学研合作及规划对标数据。
2. **第二步：外部权威政策、统计公报与高校规划原文抓取**
   - 调用 `deepseek_search` 检索教育部、省政府、省教育厅、国家自然科学基金委及目标高校官网（限定 `.gov.cn` / `.edu.cn` 权威发布），例如：
     - 教育部《全国教育事业发展统计公报》或《学位授权审核申请基本条件》；
     - 所在省份《高水平大学建设实施方案》《“双一流”/“双优”学科建设管理办法》；
     - 目标校与对标校公开发布的《“十四五”事业发展规划》《本科教学质量报告》《研究生教育发展质量年度报告》。
   - **必做动作**：对命中的每一条权威网页 URL，立即调用 `deepseek_fetch(url)` 读取完整正文，提取包含准确数字、日期和政策硬约束的原文段落。
3. **第三步：分域登记信源**
   - `sy-industry-profile`：双优建设画像与区域产业契合度核实记录；
   - `gov-policy-*` / `edu-official-*`：附带真实 `url`、`publisher`、`date` 的外部权威政策/公报信源；仅在短原文片段对读者有实际帮助时附逐字 `excerpt`，否则留空。
