# 高教研报审校清单与低密度套话手术刀（Reviewer Only）

> 说明：本文件仅在成稿审校阶段由 `reviewer` 读取，用于对已落库的 Block 进行定点诊断。

## 一、数据与口径一致性红线（最高优先级）

1. **表文/图文数字核对**：正文中提及的立项数、经费额、增长率、占比、排位，必须与同章节 `table` / `echarts` 块中的数值逐字核对（注意四舍五入位数是否统一，百分比通常保留 1 位小数）。
2. **口径边界完备性**：
   - 凡涉及“双一流/双优”、“高层次人才（国家级/省级）”、“三大奖”、“国自然/国社科”、“ESI 前 1%/1‰”等高教核心指标，检查表格或图表的 `note` / `source_note` 是否清晰界定了统计时间截点与包含范围。
   - **保留合法的口径严谨性说明**（如数据截点、未公开专项说明），**剔除无实质信息的免责套话**（如“受篇幅所限”、“不妥之处敬请批评指正”）。

## 二、低信息密度表达替换指南（发现以下模式时定位 `block_id` 并给出替换建议）

| 常见低密度模式 | 诊断标准 | 修订方向（正向替换） |
| :--- | :--- | :--- |
| **空泛程度副词堆砌**（如“取得了令人瞩目的辉煌成就”、“展现出无比强劲的发展势头”） | 删掉该分句后，段落丢失了 0 个数据点 | 直接替换为具体时间跨度内的增量、增速或排位晋升名次（如“较‘十三五’末增长 42.3%，省内排位上升 2 位”） |
| **空转折 / 伪对比**（如为了凑句式强行写“这不仅是…更是…”、“不是简单的数量叠加，而是质的飞跃”但后文没有任何结构指标支撑） | “而是/更是”后面接的是抽象口号而非具体结构指标 | 若有结构数据，直接写结构占比变化（如“重点重大项目占比由 3.1% 提升至 7.8%”）；若无结构数据，直接删去后半句口号 |
| **互联网黑话入公文**（如“底层逻辑”、“组合拳”、“打法”、“赋能”、“抓手”滥用、“闭环”） | 不符合高校发规处/教育部正式公文与学术研报语体 | 替换为标准高教公文术语：如“体制机制”、“协同举措”、“建设路径”、“支撑作用”、“突破口/关键载体”、“全流程管理” |
| **机械过渡连接词**（每段开头固定出现“与此同时”、“值得注意的是”、“综上所述”、“总而言之”） | 连续两个及以上段落以同质化连接词起首 | 直接删去句首过渡词，以主语（指标名称、学科名称或年份）直接起句 |
