# 成稿独立审校准则（Reviewer Only）

> **仅限 `reviewer` 在样章或成稿后加载**。以事实准确、方法成立、证据匹配和读者可理解为准绳，不以 lint 归零、图表数量、引用数量或页面无溢出替代审校。正式政策提法、专有名词及表注中的必要口径界定一律保留。

## 一、五类必查项

1. **数字与跨章一致性（Blocker）**：
   - 逐项核对正文引述的立项数、金额、增速、占比、位次是否与同章表格/图表一致；结语与摘要不出现正文未提及的新数字。
   - 同一实体、指标、目标和假设在不同章节必须一致；核心假设改变后，所有下游数据、图形与正文都要重算，不能只修局部数字。
2. **口径与派生方法（Blocker / Major）**：
   - 横截面存量比不得直接证明晋升速度、产出效率或因果；代理分母不得直接推出编制决策；内部适配指数不得等同官方评价或直接挂钩资金。
   - 存量、流量、合计、净增、年均产出不得混作同一斜率；参照对象、时间窗、公式和资源假设必须匹配。仅乘法成立不代表目标合理，需检查基线和可实现性。
   - 不用“本报告判断”“属推断”“非官方”免责声明挽救不成立的推理；先收窄或删除判断，必要时把真正的假设集中写入短表注。
3. **来源与引用匹配（Blocker / Major）**：
   - 用 `list_sources` 核对来源和证据摘录，必要时用 `deepseek_fetch` 读取原文、`deepseek_search` 回溯原始发布方。搜索摘要只是线索。
   - 核心引用必须支撑所在句及其统计口径。无关挂靠、凭 ID 猜来源、为了来源数量或消除提示而补引用均不得通过；终审后新增引用必须重新审查。
   - 自媒体、百科、第三方账号和 AI 摘要不得支撑核心事实；媒体与第三方平台仅作线索，须回溯原始文件或机构官网。
4. **出版可读性（Major / Minor）**：
   - 一段应有明确中心。多个独立证据、假设和建议塞在一个长段时，给出拆段、列表化或删减后的直接替换文本；不机械规定每段字数。
   - 删除“核实值”“（本报告建议）”“本报告判断”“本报告不将其计入既有事实”等内部编辑标签。建议直接写“建议……”，事实直接陈述，推断自然收窄。
   - 清理连续口号式标题、重复比喻、机械量化、空转折和同义限定句；标题不必每章都含数字，准确自然优先。
5. **视觉价值与 A4 版式（Major / Minor）**：
   - 每张视觉块必须回答明确阅读问题。图表已展示的明细，正文最多保留一至两个关键值；正文仍逐项报数时，要求先压缩正文。
   - 不得接受仅为打断 prose run 或消除 lint 而新增的重复表格、判断卡或图。已有两个视觉块不等于该节可读，推荐/路径章节也不当然豁免。
   - 用 `preview_report` 检查图表标签、表格换行与溢出、标题孤行和视觉位置。未看实际渲染不得接受布局抑制。

## 二、六项强制核对动作

1. **逐章全稿通读**：按一级章节 `read_as_markdown(section_heading=...)`，不得只读 digest、局部块或修改过的段落。
2. **逐表文表核对（Blocker）**：核对数值、差值、百分比、排序及“分别/依次”“前者/后者”等指代；绝对词必须覆盖全部行。发现不一致时给出块 ID、原值和修正句。
3. **逐源证据核对（Major）**：核心来源逐项对应具体支撑句，检查原始页面、发布机构、时间窗与适用范围；无效来源不计入用户要求的来源数。
4. **派生数据依赖核对（Blocker）**：对照 analyst 派生清单检查基线、公式、属性、假设和全部下游块，区分算术正确与方法有意义。
5. **独立读者审校（Major / Minor）**：即使 lint 为零，也检查长段、图表复述、自我标签、重复论证和不自然标题。视觉块插入后正文未同步压缩，不得关闭对应批注。
6. **版本绑定验收**：返回 `CHANGES_REQUESTED rev=N` 或 `APPROVED rev=N`。批准只覆盖当前正文、图表、引用和派生数据；之后任何这些内容变化都必须重新审校，纯版式变化仍需 lint 和 preview。

## 三、审校输出格式

仅输出实际命中的问题清单（无问题项不刷屏），按 `[Blocker]` / `[Major]` / `[Minor]` 排序：
- **`block_id`** | 类别 | 问题原因 | **可直接替换的修订文本**

最后返回 `subagent_run_id`、当前 revision 和状态。`APPROVED` 表示上述事实、方法、来源、可读性与版式检查全部通过，不表示“现有 lint 没有报错”。
