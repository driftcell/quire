# 高等教育研究报告独立审阅清单（Reviewer Rubric）

> **仅限 `reviewer` 在样章或成稿后加载**。以事实准确、方法成立、证据匹配和读者可理解为准绳，不以 lint 归零、图表数量、引用数量或页面无溢出替代审校。正式政策提法、专有名词及表注中的必要口径界定一律保留。

## 一、静态 Lint 与协议合规（零阻断门禁）

- [ ] **零 Error**：`lint_document(doc_id)` 的 `summary.errors == 0`（无 `QR101` 悬空引用、`QR107` 引用语法错误、`QR201/QR303` 空表空图、`QR401` 占位符、`QR411` 段落内嵌 Markdown 表）。
- [ ] **引用语法纯净**：所有行内引用均为纯 `[^source_id]`（或连写 `[^id1][^id2]`），无 `[^id: 标题]` 或 `[^id1, id2]`。
- [ ] **封面与全局配置完整**：中文报告的 `toc.title` 为“目录”、参考文献标题为“参考文献”；封面已配置副标题、作者/机构与日期，页眉页脚已启用且未擅自开启章节强制分页。

## 二、标题结论化与目录可读性（对应 `QR418`）

- [ ] **H1 与 H2 全部采用 `<分析对象或切面>：<具体比较结论或结构性判断>`**：检查每一个 H1 和 H2 是否都包含冒号及基于本节真实证据得出的具体量化/结构性结论，且未套用生硬口号或重复模板句式。
- [ ] 无判断的裸话题名词短语或仅报数量的裸计数空壳标题一律要求升级为结论化标题，且批注中不预设死板示范标题，要求按本节核心证据原创提炼。

## 三、信源 `excerpt` 与跨章口径（对应 `QR101–QR105`）

- [ ] **`SourceEntry.excerpt` 原文覆盖与反口袋信源审查**：调用 `list_sources(doc_id)`，将正文和表格中挂有 `[^source_id]` 的核心数字与对应 `excerpt` 逐一核对。若发现伪造单一笼统的“公开数据汇编”口袋信源、或根据 `note` 脑补编造未实际抓取的网页 `excerpt`、或某来源 `excerpt` 未包含所引数字，一律标 `[Blocker]` / `[Major]` 要求核实原文并按真实数据域分项登记或修正引文归属。
- [ ] **跨章/跨表/跨图数字零冲突**：同一指标（平台数、专任教师与博士占比、高层次人才数、自科立项数、产业契合度得分等）在导论、各章正文、表格、ECharts 数据与结语中完全一致。
- [ ] **来源权威性**：核心事实只接受政府主管部门、高校官网、统计年鉴、基金委、权威学术数据库或榜单原始发布方；自媒体、百科、第三方账号与 AI 摘要仅作线索，无法回溯的按未核实处理。

## 四、图文穿插密度与 A4 版式（对应 `QR2xx` / `QR3xx` / `QR419`）

- [ ] **消除连续纯文墙与节首裸图（`QR419`）**：每个数据论证型 H2 至少有一个表格或图表支撑；最佳穿插结构是“1–2 段核心判断引出 → 表格/图表 → 4–6 段围绕图表的拆解、归因与对策”，不得出现图表孤立在节首或后面连续十余段纯文字的情况。
- [ ] **表格 A4 舒适度、信息饱满度与单位自洽（`QR204` / `QR205`）**：叶子列通常 6–8 列、硬上限 9 列；在 `preview_report` 下 `overflow_x_count == 0`、`narrow_wrapped_column_count == 0`。3–5 列定性对比表（制度对照、映射矩阵、风险清单）的文本单元格应有 10–22 字完整业务表述，若被砍成 4–6 字电报口号须要求补全制度细节。行向多指标表第一列指标名须在括号内标注每行单位（`（人）`、`（%）`、`（项）`、`（分）`）。
- [ ] **ECharts 图表规范（`QR3xx` / `QR420–QR422`）**：外层 `title` 未在 `option.title` 中重复（`QR312`），`note` 无 `注：` 前缀（`QR420`），`source_note` 无“资料来源：”等前缀（`QR421`），每个图表/表格均绑定 `source_ids` 或 `source_note`（`QR422`）。
- [ ] **版式实测**：用 `preview_report(doc_id, block_ids=[...])` 检查真实渲染；局部预览会自动隐藏封面与目录，第 1 页直接展示目标块。版式问题与内容问题分别记录，不用页面无溢出替代可读性判断。

## 五、出版语言与论证纵深（对应 `QR412–QR417` / `QR424` / `QR426`）

- [ ] **论证纵深与段落饱满度**：每个 H2 小节应具备充分的论证展开（通常 5–8 个高密度自然段，完整覆盖核心判断、结构反差拆解、体制机制成因与具体建设动作）。若某小节仅有 2–3 个干瘪短段（或单段仅一两句话敷衍收尾），必须标 `[Major]` 要求结合既有数据与机制深度展开。
- [ ] **零内部系统术语（`QR424`）**：无 `指标库口径`、`指标库记录`、`学科云`、`双优库`、`FacultyInfo`、`includeSub=true`、`local:4.1.1`。
- [ ] **零审稿元标签与章节边界自白（`QR426`）**：无“（核实值）”“（属推断）”“本报告建议”“是基于学科名称的推断”，也无“本节只确认……”“在行动路径章统一处理”“需要在申报口径上收敛的一处细节”等内部工作底稿语言。
- [ ] **无凑字数注水段**：若小节末尾存在为凑字数重复前文同一论点、或强行插入与小节主线无关的补丁段，要求删并精简。
- [ ] **读者审校**：逐段检查多中心长段、图表明细复述、机械量化、连续口号式标题和免责声明堆叠，并给出可直接替换的文本。

## 六、事实、方法与建议的边界

- [ ] **数字与排序**：逐表核对正文数值、差值、百分比、优劣顺序及“分别/依次”“前者/后者”等指代；绝对词必须覆盖全部行。发现不一致标 `[Blocker]`，指出块、原值和修正句。
- [ ] **口径与派生方法**：横截面存量比不得直接证明晋升速度、产出效率或因果；代理分母不得直接推出编制决策；内部适配分不得等同官方评价或直接挂钩资金。
- [ ] **派生测算**：同时审查方法与算术，存量、流量、合计、净增、年均产出不得混作同一斜率；参照对象、时间窗、公式和资源假设必须匹配。仅乘法成立不代表目标有意义。核心假设改变后，所有下游值未同步重算的标 `[Blocker]`。
- [ ] **建议与推断**：建议直接写“建议……”，推断通过收窄判断表达；不用“本报告判断”“属推断”“非官方”免责声明挽救不成立的推理。
- [ ] **视觉价值**：每张视觉块必须回答明确阅读问题。正文仍逐项报数、视觉块只为打断 prose run、同一数据重复出现时，要求先压缩正文，再由 analyst 归并或删除低价值视觉；不得为消 lint 补图。

## 七、强制核对动作与版本绑定

1. **逐章全稿通读**：按一级章节 `read_as_markdown(section_heading=...)`，不得只读 digest、局部块或修改过的段落。
2. **逐表文表核对**：核对数值、差值、百分比、排序及指代，发现不一致时给出块 ID、原值和修正句。
3. **逐源证据核对**：核心来源逐项对应具体支撑句，检查原始页面、发布机构、时间窗与适用范围；无效来源不计入用户要求的来源数。
4. **派生数据依赖核对**：对照 analyst 派生清单检查基线、公式、属性、假设和全部下游块。
5. **全量 `lint_ignore` 审计**：按全量块清单检查，不只看本轮改动或近期告警；当前版本不再触发的陈旧抑制要求清除，仍触发者须有当前版本证据。
6. **版本绑定验收**：返回 `CHANGES_REQUESTED rev=N` 或 `APPROVED rev=N`。批准只覆盖当前正文、图表、引用和派生数据；之后任何这些内容变化都必须重新审校，纯版式变化仍需 lint 和 preview。

## 八、审校输出格式

仅输出实际命中的问题清单（无问题项不刷屏），按 `[Blocker]` / `[Major]` / `[Minor]` 排序：

- **`block_id`** | 类别 | 问题原因 | **可直接替换的修订文本**

最后返回 `subagent_run_id`、当前 `revision` 和状态。`APPROVED` 表示上述事实、方法、来源、可读性、版式与全量抑制检查全部通过，不表示“现有 lint 没有报错”。
