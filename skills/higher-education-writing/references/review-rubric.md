# 成稿独立审校准则（Reviewer Only）

> **仅限 `reviewer` 在成稿后加载**。以事实准确性与信息密度为准绳，不搞机械字面一刀切（正式政策提法、专有名词及表注 `note` 中的口径界定一律保留）。

## 一、 四类必查项

1. **数字与一致性（Blocker）**：
   - 运行 `lint_document` 确认零 error；
   - 逐项核对正文引述的立项数、金额、增速、占比、位次是否与同章表格/图表完全一致；结语与摘要不出现正文未提及的新数字。
2. **口径与推理（Major）**：
   - 检查表格/图表的 `note` 是否写明统计年份与包含范围；
   - **删除测试**：若某句限定/说明删去后读者不会误用数据（如“受篇幅所限”“以上判断仅供参考”“本报告认为”“经联网检索”），直接删除；若会误用，则把口径写进 `note` 或收窄判断本身。
   - 不写“样本”“变量”“Spearman相关系数”“HHI”等论文腔统计术语作正文论据（确需时转为管理含义）。
3. **表达密度与去黑话（Major / Minor）**：
   - **空洞副词与互联网黑话**：删去“底层逻辑、范式跃迁、生态位、护城河、飞轮、颗粒度、深度赋能、打法”及无数据支撑的“显著提升、令人瞩目”，替换为真实增幅、位次或标准公文术语（如“体制机制”“协同举措”“建设路径”）。
   - **空转折与重复连接词**：删去后半句无实质差别的“……，但不构成简单对应”“……，值得进一步观察”；连续段落不再重复用“与此同时”“值得注意的是”起首，直接用指标或学科主语起句。
   - **平淡/计数标题**：把“××建设情况”“三个约束条件”等改写为带具体对象和判断的标题（参考 `references/examples.md`）。
4. **A4 排版巡检（Minor）**：
   - 运行 `preview_report` 检查是否存在图表标签遮挡、表格溢出或标题孤行。

## 二、 三项强制核对动作

1. **逐表文表数字与排序核对（Blocker）**：
   - 对 `read_as_markdown` 中的每一张 `表 N` 与 `图 N`，逐一核对同章正文里的数值、差值、百分比、优劣顺序（“占优/反超/居首”）及“第 N 项/前者/后者”指代。
   - 只要正文与表格数值或优劣顺序不一致，立即标 `[Blocker]`，指出 `block_id`、表格原值并给出可直接替换的修正句。
2. **跨章口径一致性核对（Blocker）**：
   - 以主编下发的 `shared_facts` 为基准，检查同一实体或指标在不同章节是否一致。
   - 例如同一高校的学科评估档位不能前章写 `B`、后章写 `B+`；同一笔专项资金的时间窗口不能表注写 `2024—2025年`、正文写成“十四五”期间。
3. **信源权威度与残留模板复核（Major）**：
   - 核查参考文献：若使用 `baike.baidu.com`（百度百科）、`toutiao.com`（今日头条）、`sohu.com`（搜狐自媒体）等非一手信源支撑核心政策或数据，标 `[Major]`，建议替换为 `.gov.cn` / `.edu.cn` / 官方媒体来源。
   - 复核是否仍有残留的空泛标题或长段机械枚举，给出 `block_id` 与改写建议。

## 三、 审校输出格式

仅输出实际命中的问题清单（无问题项不刷屏），按 `[Blocker]` / `[Major]` / `[Minor]` 排序：
- **`block_id`** | 类别 | 问题原因 | **可直接替换的修订文本**
